# Copy lineages

> **Hatnote.** Where 0728 sits among named laptop-data objects. JPMI’s encyclopedia covers the Mac Isaac disk in depth. This page is the **0728-facing** map.

```text
MacBookPro14,1 internal SSD (never directly imaged here)
        │
        ▼
Mac Isaac retained-copy universe (Apr 2019 → later copies)
        ├─► JPMI / Crucial X6 HFS+ Untitled          [not 0728]
        ├─► GAI HFS+ Biden Lap 2                     [not 0728]
        ├─► APFS bootable SanDisk HB Boot Drive      [not 0728]
        │       TRIMARCO → … → TODD → HAYES
        │                         ├─ MPOLO (Jun 2021 bootable, Marco Polo)
        │                         └─ APFS* (RHB_Boot.imgc MEGA 13 Jun 2022 → this author)
        └─► 0728 Extra Found Files                   [this encyclopedia]
                R-Studio export, Jul 2021
                MEGA: Hayes → Ziegler → author (Aug 2021; first known download)
```

**0728 is a separate corpus.** It is not a clone of JPMI, APFS, or GAI. The same bag contains blobs that match **all three**, each **pair**, each **singleton**, and **none**.
