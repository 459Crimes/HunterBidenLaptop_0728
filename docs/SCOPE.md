# Scope (what this encyclopedia is not)

> **Hatnote.** Boundary page. Main article: [README](../README.md).

## In scope

One corpus: the **Extra Found Files** tree stamped **28 July 2021**, indexed here as **0728**, together with the **Conan James Hayes** custody, method, and public-record file attached to it.

Questions this repo is built to answer:

- What kind of storage object is 0728 (tree vs image vs volume)?
- What category / extension / hash populations does it contain?
- Which SHA-256 values also appear in APFS, GAI, or JPMI?
- Which dates are recovery-era vs working-copy vs content-era vs carve artifacts?
- What did Hayes say about how the files were recovered, and what does the tree show?
- Which links are still missing (MEGA logs, R-Studio project, source-volume ID)?

## Disambiguation: “the Hunter Biden laptop”

That phrase is used in public for, at least:

1. the **physical Mac(s)** at the shop;
2. the **customer external drive**;
3. **Mac Isaac preservation copies** (JPMI’s family);
4. **FBI-held** originals;
5. **Costello / Giuliani / press** extracts;
6. later **mixed internet archives**;
7. the **APFS** family (bootable siblings);
8. **0728 Extra Found Files** — related to laptop material but **not from the laptop files per se**; many unknown origin; some completely unknown to the laptop.

This encyclopedia is about **(8)**. Mixing (3), (7), or a MEGA political dump into a sentence about (8) as if they were the same object is a category error.

**Marco Polo** used **MPOLO** (Hayes bootable laptop, Jun 2021) **plus (8)**. It did **not** analyze JPMI. Hacking is **not** attributed here to (1)–(5) or to JPMI. Files of unknown origin relative to the three primary inventories live in **(8)** — that is the integrity question of *this* repo. [Integrity](INTEGRITY.md) · [Copy lineages](COPY_LINEAGES.md).
